#欢迎！

这个库存在的意义是开放它的讨论区，用于 **[giscus](https://giscus.app/zh-CN)** 生成我 **[个人网站](https://yicongl1.github.io)** 的评论区。

我的个人网站部署在Github上，目前是静态网页，没有后台的数据库（暂时的，之后会想要放数据库）

利用giscus这个工具，我可以把GitHub库的讨论区变为静态网页评论区的后台。当网页上面有人评论时，giscus会自动在讨论区生成一个页面url的annoncement，存放所有的评论。

评论支持markdown语言，还有表情！！

你自己也可以试试看！不用搭建后台的评论区！
